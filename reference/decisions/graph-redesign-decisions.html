What the probes found

  • The derivation will not shrink much: today it is 1,970 lines but only 920 code lines. The redesigned derivation is about 970 code lines with the scope you added, about 8% smaller like for like. The package still shrinks in types.jl, the DSL, the test bridge and kcat.
  • One joint solve over bare constants is deterministic (0 differences in over 10,000 permutations and regroupings). Today's package changes fitted names in 312 of 663 same-model regroupings.
  • Deriving both conformations from one step list removes ROADMAP known issues 1 and 2 (142 phantom names, 39 fold hazards) and every 1 ^ n artifact.
  • Horner code generation keeps 0 allocations and cuts the slowest law from 120.8 to 41.5 ns, compile time by 78% on large laws. It is independent of the rest.
  • The graph Mechanism builds in about 1 µs (13× faster) with exact equality and process-stable hashes on 2,799 mechanisms.
  • A rename-proof key is exact (0 false merges in 809), about 70 µs per law, and merges 17–26% of allosteric expansion classes.

What the vertical slice found

  • One chained prototype of the decided design derived 237,965 laws from 257,698 mechanisms, all 250,855 ter-ter seeds included. Every law matches its oracle, and no compiled law allocates.
  • Keys are stable across processes and about 31,700 rewritten inputs, the solve is identical across 37,849 same-model regroupings, and :OnlyA admission matches an exact LP on all 2,995 allosteric records.
  • Code size stays about the same: derivation 926 → 1,110 lines (printing 72 → 174, for the coefficient form, the Cleland normalizer and allosteric printing), type layer about 708 → 562, enumeration moves about 411 → 308. Total about 2,045 → 1,980 (−3%), before 30–40 lines of fixes.
  • The largest bi-bi laws run in about 42 ns; PR #85 already brings the slowest of them to 54 ns. 343 ter-ter laws run over 120 ns (card E1).
  • Fixes the spec takes without a decision: the key labels concentrations by name (by position, an inhibitor I and an inhibitor J share a key); input checks for an all-rapid-equilibrium mechanism and a declared substrate no step uses; exact roots for exponents such as 1/3; the allosteric size cap on both conformations together; and the tagging move calling admission.
  • AD14 and AD14b are admitted, not rejected: with per-step classes (B2) their cone is feasible and the limit equals deletion.
  • Today's expand_mechanisms crashes on some ter-ter seeds: the :OnlyA guard built its check graph through the validating Mechanism constructor. PR #87 fixes it; old and new guard agree on all 219,894 tag sets where the old one gave a verdict.
