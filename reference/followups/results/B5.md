Denis, the short answer is yes. Full mode does not write a law in which every listed constant appears. Its `v` line is exactly the Reduced `v` line, minus the dependent assignments, with every group constant read from `params`. That line is built along a breadth-first spanning tree of each RE segment, so it names only the K's on the tree. In Reduced mode the off-tree K still reaches `v` through the Wegscheider dependent of a tree K. Full mode deletes that line, so the off-tree K is read in from `params` and never used. **1. How Full mode builds its law** (all in `src/rate_eq_derivation.jl` unless another file is named)
- **Parameter list:** `parameters(m, Full)` is `_raw_param_symbols` plus `E_total` (lines 38–39). That is one `[K]` (RE) or `[kf, kr]` (SS) per kinetic group, taken from the group's representative step (`types.jl:1426-1427`, `thermodynamic_constr_for_rate_eq_derivation.jl:22-23`).
- **No dependents:** `rate_equation(…, Full)` calls `_rate_body(M, (raw…, :E_total), Dict())` (line 440). The empty `Dict()` means no dependents, so no Haldane and no Wegscheider. The string version is lines 538–539.
- **Same polynomial in both modes:** both modes get num/den from `_num_den_exprs` → `_raw_symbolic_rate_polys(M)` with default arguments (lines 354, 396). That default includes the single-symbol tie rename (line 231), so Full mode does apply those ties.
- **RE weights by BFS:** `_compute_alpha` (lines 154–197) roots each segment at the form with the fewest bound metabolites (lines 122–126). It then pops forms and scans the RE steps in stored flat order (line 166). The first step to reach an unvisited form sets that form's weight (lines 171–177), and an off-tree step's K is never read.
- **Why nothing complains:** the after-check (lines 183–195) compares only the concentration part of each RE ratio (line 191). Around a loop that does not carry the reaction those always match, so the check passes.

**2. Example: expand_bibi/265, one of the 23**

The "RE Random Bi-Bi" spec does not qualify. Its inner bindings are SS (`E(A) + B <--> E(A, B)`), so the loop is not RE-only, and all 12 listed constants appear in its Full `v` (checked). expand_bibi/265 does qualify:
```
E + A ⇌ E(A);  E + B ⇌ E(B);  E(A) + B ⇌ E(A, B);  E(B) + A ⇌ E(A, B)
E(A, B) <--> E(P, Q);  E(P, Q) ⇌ E(P) + Q;  E(P) ⇌ E + P
```
```
(; K_EA_to_E_A, K_EB_to_E_B, K_EP_to_E_P, K_EAB_to_EA_B, k_EAB_to_EPQ, k_EPQ_to_EAB, K_EAB_to_EB_A, K_EPQ_to_EP_Q, E_total) = params
v = E_total * (k_EAB_to_EPQ * A * B / (K_EAB_to_EA_B * K_EA_to_E_A) - k_EPQ_to_EAB * P * Q / (K_EPQ_to_EP_Q * K_EP_to_E_P))
  / (1 + A / K_EA_to_E_A + B / K_EB_to_E_B + P / K_EP_to_E_P + A * B / (K_EAB_to_EA_B * K_EA_to_E_A) + P * Q / (K_EPQ_to_EP_Q * K_EP_to_E_P))
```
`K_EAB_to_EB_A` (A binding to E(B)) is listed but never appears in `v`.

- **Step order in the DSL changes nothing.** The same steps in shuffled order give a mechanism that is `===` this one. The constructor sorts steps and groups by the rendered names of from-form, to-form, consumed and released (`types.jl:634-636`, `669-671`).
- **Names decide the tree.** Starting from E, the scan reaches "EA" before "EB", so E(A, B) gets its weight through E(A) + B, and E(B) + A becomes the step that closes the loop.
- **Renaming A to Z flips it.** "EZ" sorts after "EB", so the tree runs through E(B) instead. Full `v` then has `B * Z / (K_EBZ_to_EB_Z * K_EB_to_E_B)` and drops `K_EBZ_to_EZ_B`, which is B binding to E(A) in the original naming.

Concentrations: A (or Z) = 2, B = 1, P = 0.3, Q = 0.2. Constants: K(A|E) = 1, K(B|E) = 2, K(B|EA) = 3, K_EP = 0.5, K_EPQ = 0.7, kf = 10, kr = 1. Here K(A|EB) = 4, while the loop requires 1.5.

| Full mode | named A | named Z |
|---|---|---|
| K(A\|EB) = 4 | 1.31533 | 0.51501 |
| K(A\|EB) = 1e6 | 1.31533 (no change) | −0.04013 |
| K(B\|EA) = 1e6 | −0.04013 | 0.51501 (no change) |

Each naming silently ignores a different physical constant.

How widespread this is: 27 of the 806 plain mechanisms have a loop of RE steps whose kinetic grouping does not make its cycle relation hold automatically.
- **23 drop a listed K, and which one depends on names:** 21 expand_bibi, plus handwritten/12 and handwritten/15.
- **3 specs:** the single-symbol tie closes the loop inside the Full polynomial. In Non-competitive Inhibitor, for example, Full lists `K_ERinhS_to_ERinh_S` but `v` uses `K_ES_to_E_S` in its place.
- **handwritten/24:** no listed name goes missing, but the loop's relation `K_E_to_F = 1` is not imposed.

**3. Reduced mode for the same mechanism**
```
(; K_EAB_to_EB_A, K_EA_to_E_A, K_EB_to_E_B, K_EPQ_to_EP_Q, K_EP_to_E_P, k_EAB_to_EPQ, Keq, E_total) = params
# Wegscheider constraints:
K_EAB_to_EA_B = K_EAB_to_EB_A * (1 / K_EA_to_E_A) * K_EB_to_E_B
# Haldane constraints:
k_EPQ_to_EAB = (1 / Keq) * (1 / K_EAB_to_EB_A) * (1 / K_EB_to_E_B) * K_EPQ_to_EP_Q * K_EP_to_E_P * k_EAB_to_EPQ
v = (character-for-character the Full v line)
```
The tree K is now a dependent fixed by K1·K3 = K2·K4, so both routes give the same number. With the cycle-consistent value K(A|EB) = 1.5 and Keq = 7/6, all four evaluations (Full and Reduced, A-named and Z-named) give 1.3153326904532303.

**4. Why imposing the RE-only cycle relation in AllParameters fixes it**

Rapid equilibrium fixes the ratio of the two forms joined by each RE step. Around a loop, those ratios must multiply back to 1. Otherwise no set of form concentrations satisfies all four equilibria at once, and E(A, B)/E has two values: AB/(K(A|E)·K(B|EA)) along one route and AB/(K(B|E)·K(A|EB)) along the other. Today the BFS picks one of them by name order.

Making K(A|EB) = K(A|E)·K(B|EA)/K(B|E) a dependent in AllParameters fixes three things:
- both routes give the same number, so the choice of tree stops mattering;
- the parameter list holds only constants that reach `v`;
- a fit no longer depends on what the metabolites are called.

This is part of what the RE approximation means, not an optional thermodynamic constraint. It never involves Keq, because an RE loop that carries the reaction is already rejected (lines 187–194).

Loops that contain any SS step are different. A steady state exists and is unique for any positive constants. If those constants break detailed balance, flux simply circulates around the loop: thermodynamically wrong, but well defined, and every constant appears in `v`. AllParameters can therefore keep Haldane and every SS or mixed SS/RE Wegscheider relation off. Only loops made entirely of RE steps get a dependent. The 3 specs above show this is a generalization of the single-symbol tie that Full mode already applies silently (inference from the code paths above).
